# LDSW 3.4 Utilización de widgets

Este proyecto es una aplicación Flutter creada como parte de la actividad 3.4, utilizando los widgets básicos: **Text**, **Row**, **Column**, **Stack** y **Container**.

## Tecnologías utilizadas

- Flutter 3.29.3
- Dart 3.7.2
- DevTools 2.42.3

## Cómo ejecutar el proyecto

1. Clona el repositorio:

   ```bash
   git clone https://github.com/epickatif/ldsw_3_4_utilizacion_widgets.git
   cd ldsw_3_4_utilizacion_widgets
   ```

2. Ejecuta en un dispositivo o emulador:

   ```bash
   flutter run
   ```
